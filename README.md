# NIA SKIN

**NIA SKIN** is a beginner-built skincare website project designed to make discovering and exploring skincare products simple and accessible.

## About the Project

NIA SKIN is a web development project focused on creating a simple online skincare shopping experience. It allows visitors to explore skincare products, view product information, and add products to a shopping cart.

The project is currently under development.

## Features

- Homepage with a welcome section.
- Navigation between Home, Products, About, and Reviews.
- Skincare product listings.
- Product details popup (modal).
- Add products to the shopping cart.
- Shopping cart item counter.
- Automatic total price calculation.
- Increase and decrease product quantities.
- Clear shopping cart functionality.
- Cart data saved using browser Local Storage.

## Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Website styling and layout.
- **JavaScript** – Interactive features and shopping cart functionality.
- **Local Storage** – Saving cart information in the browser.
- **Git and GitHub** – Version control and project hosting.

## Getting Started

To run the project on your computer:

1. Clone the repository:

```bash
git clone https://github.com/wamaraedigartushabe-arch/SKINNELY.git
```

2. Open the project folder:

```bash
cd SKINNELY
```

3. Open `NIATECH.html` in your web browser.

You can also open the folder using Visual Studio Code and edit the HTML, CSS, and JavaScript files.
